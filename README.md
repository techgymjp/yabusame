# 流鏑馬 — YABUSAME

疾走する馬の上で鐙に立ち（立透かし）、弓手（左）側に並ぶ三つの的を鏑矢で射抜く 3D ゲームです。
ブラウザだけで動き、ビルドは不要です（three.js を `vendor/` に同梱）。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| マウス | 狙う（クリックでポインタロック） |
| 左ボタン長押し / 離す | 弓を引く / 矢を放つ |
| W・S | 馬を追う・抑える |
| C | 視点の切替（肩越し・一人称・後方） |
| Esc | 一時停止 |

スマートフォンでは画面をなぞって狙い、「引く」ボタンを押して離すと放ちます。

## 再現していること

- 馬場は二町（約218m）、的は一尺八寸（約54.5cm）の檜板を三つ。弓手側に設置
- 交叉襲歩（左後→右後→左前→右前）の脚運びと、それに合わせた上下動・蹄音
- 上下動は騎手の視点と狙いに直接響く。満を持し過ぎると手が震える
- 矢には馬の速度がそのまま乗るため、真横に向けて放っても前へ流れる（見越しが必要）
- 鏑矢の重力・空気抵抗・風、鏑の風切り音、命中すると板が割れて飛び散る
- 和弓は握りが下寄りの非対称形。矢は弓の右側につがえる
- 綾藺笠・行縢・射籠手の狩装束、障泥・厚総をつけた馬、鳥居・幟・紅白幕・紅葉の馬場

## 射法

左ボタンを長押しすると、弓を頭上へ掲げる**打起し**、引きながら目の高さへ下ろす**引分け**、引き切った**会**へと進みます。
離すと**離れ**。弦が戻ると同時に弓が手の内で回る**弓返り**、右手が後ろへ抜ける**残心**を経て、箙から次の矢をつがえます。
射手は左肩を的へ向けた横向きの胴造りで、右手は右頬まで引き、右肘を後ろへ張ります。
標準の「肩越し視点」は射手の胸側やや後ろから見るので、引く動作・しなる弓・その先の的が一度に見えます。
放った矢は光の尾を引き、一瞬スローになるので軌道を目で追えます。照準点は弓を引いている間だけ表示されます。

## 馬のモデル

筋肉・骨・関節の形（肩甲、臀部、前腕、飛節、球節、蹄、頬、鼻孔、耳など約90個）を距離関数で滑らかに合成し、
Surface Nets で一体の曲面メッシュを生成しています。骨格（首2・頭・尾・各脚3関節）にスキニングし、
接地中は蹄を地面に平らに保ち、球節が沈み込む襲歩の脚運びをします。毛色は鹿毛で脚先は黒、額に流星。

## 描画

- 手続き生成の PBR 風テクスチャ（砂・土・草地・樹皮に法線マップ）
- 風になびく草（高画質で約20万本）と芒、葉カードで作った杉並木・紅葉・銀杏
- 雲の流れる空、霞む山並み、蹄跡の残る馬場
- 断面補間で作った曲面の馬（鹿毛・脚先の黒・たてがみと尾）
- ポストエフェクト：環境遮蔽（GTAO）・ブルーム・色調補正・周辺減光・疾走時の放射ブラー
- タイトル画面で画質（高・中・低）を切り替え可能。スマートフォンは既定で低

## 難易度

- 初級：矢5本・約43km/h・着弾予測を表示
- 中級：矢4本・約50km/h・照準点のみ
- 本式：一的一矢（3本）・約56km/h・照準表示なし

## ローカルで動かす

ES モジュールを使うので、ファイルを直接開かずに簡易サーバで配信してください。

```bash
python3 -m http.server 8000
```
